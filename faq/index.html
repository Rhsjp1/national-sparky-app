Frequently asked questions

Quick answers about SparkySolve for North Carolina electricians.

Is SparkySolve only for North Carolina?

It is optimized for NEC 2023 adoption in North Carolina, but the code references apply across NEC-jurisdiction states.

Can it do commercial design work?

Yes. Use it for panel scheduling, service sizing, load calculations, and circuit questions with NEC references.

Does it replace my code book?

It supplements it. Think of it as instant lookup and first-pass review, not a substitute for official code authority.

How is it different from generic AI?

SparkySolve is domain-specific: it prioritizes safety, cites NEC articles, and avoids guesses on compliance questions.
