# SEO Submission Checklist

## Sitemap URL
`https://national-sparky-app.vercel.app/sitemap.xml`

## Google Search Console
1. Open https://search.google.com/search-console/sitemaps
2. Select the property for `national-sparky-app.vercel.app`
3. Paste the sitemap URL above and submit

## Bing Webmaster Tools
1. Open https://www.bing.com/webmasters
2. Sign in and select your site
3. Go to Sitemaps → Submit sitemap
4. Paste the same sitemap URL

## After submission
- Both will show “Success” or “Processing”
- Bing also supports RSS/Atom feeds if you add one later
- Google shows a “Last processed” timestamp once crawled
